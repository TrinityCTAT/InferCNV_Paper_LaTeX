\section*{Availability of data and materials}\label{sec:availability}

inferCNV is an R package released under the BSD 3-clause licence. It is available from Bioconductor (https://bioconductor.org/packages/infercnv) \citep{infercnvBioc} and GitHub (https://github.com/broadinstitute/infercnv), with documentation on the GitHub wiki (https://github.com/broadinstitute/infercnv/wiki). A Docker image with all dependencies is available at https://hub.docker.com/r/trinityctat/infercnv. Example data sets with run scripts are at https://github.com/broadinstitute/inferCNV\_examples, and a tutorial is at https://github.com/broadinstitute/infercnv\_workshop \todo{confirm public URL}. This article describes release \todo{version to be set by the maintainer}.

Scripts for the analyses in this article are available at https://github.com/TrinityCTAT/InferCNV\_Paper \todo{confirm public before posting}. The simulation toolkit is at https://github.com/broadinstitute/inferCNV\_benchmarking.

All data analysed in this study are publicly available. Oligodendroglioma and glioblastoma Smart-seq2 data (Figs.~\ref{fig:1}--\ref{fig:3}) are from the inferCNV package and the inferCNV\_examples repository \citep{tirosh2016oligo, patel2014}. The 10x PBMC 3k, TNBC1 and BCH869 matrices are from the xclone-data repository \citep{tenx2016pbmc3k, xclonedata}; MM199 counts are from GEO GSE141299, BCC06 and BCC06post counts from GEO GSE123813, and their whole-exome copy number segments from the Zenodo deposit of \citet{schmid2025zenodoTruth}. The breast cancer atlas used for scaling is GEO GSE176078 \citep{wu2021breast}, and the colorectal cancer atlas used for simulation parameters is GEO GSE178341 \citep{pelka2021}. Smart-seq2 reads of the H3K27M gliomas and synovial sarcomas are from the original studies \citep{filbin2018, jerbyarnon2021} \todo{add public accessions}. Kinnex PBMC and Visium HD data sets are from PacBio (https://downloads.pacbcloud.com/public/dataset/Kinnex-single-cell-RNA/); LongBench data are GEO GSE303762 and s3://longbench-data \citep{you2025longbench}; ccRCC organoid data are Zenodo record 14697181 and ENA PRJEB73513 \citep{zajac2025ccrcc}; and CCLE copy number was obtained from cBioPortal (study ccle\_broad\_2019) \citep{cerami2012cbioportal, ghandi2019ccle}.
