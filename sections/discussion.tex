\section{Discussion}\label{sec:discussion}

inferCNV turned a method first used in individual tumour studies into a general-purpose package, and it has become one of the most widely used tools for inferring CNAs from single-cell transcriptomes. Here we have described its algorithm and implementation in detail, so that results obtained with it can be interpreted with knowledge of what the code does, and so that the method can be cited.

Compared with other methods, inferCNV's main contributions are the following.
\begin{itemize}
\tightlist
\item Copy number states are calibrated by simulation for each data set. The six-state HMM learns the expected signal of each level from simulated CNAs matched to the depth and dropout of the data, rather than fixing three states or reporting continuous ratios, and distinguishes up to three extra copies \citep{schmid2025}.
\item Calls are assessed with a Bayesian model, which gives the posterior probability of each state for every predicted region.
\item The resolution of the analysis can be chosen. The HMM can run on single cells, CNA-based subclusters or whole annotation groups, and subclusters can be defined by graph clustering or by a permutation test of the cell dendrogram.
\item Several normal cell types can serve as a bounded reference, which limits the signal from cell-type-specific expression.
\item The residual-expression heatmap has become a standard display of single-cell CNAs.
\end{itemize}
Because inferCNV uses expression alone and needs only a count matrix and a gene order file, it applies to any organism and platform. This includes inbred mouse models, data available only as count matrices, and plate-based or single-nucleus protocols with uneven coverage of variant sites.

The method also has limitations. The most important is its dependence on the reference. inferCNV measures copy number relative to the reference cells chosen by the user. A reference that differs in lineage from the observations, or that carries CNAs itself, distorts the signal. On a euploid data set, inferCNV called extensive aneuploidy when the reference was a different cell type or an external data set \citep{schmid2025}. In our analyses, false calls on cells without CNAs rose from 6\% with a per-cell-type reference of normal blood cells to 16--45\% with a reference of another lineage (Fig.~\ref{fig:6}a). In glioblastoma, nine normal cells from the tumour itself gave a cleaner background than over a thousand bulk brain profiles (Fig.~\ref{fig:3}b). Without a reference, the baseline is the mean of all cells, as in the first pass of the original procedure \citep{puram2017}. When most cells are malignant, the shared tumour profile then becomes the baseline and the normal cells appear altered. Adding non-malignant cells, or a second run with the normal cells identified in a first run as the reference, avoids this inversion \citep{song2025}.

inferCNV does not classify cells as malignant or normal. The original studies combined a CNA magnitude score with each cell's correlation to the tumour's average profile \citep{venteicher2017, puram2017, neftel2019}. That approach, which infercna implements \citep{laffy_infercna}, can be applied to inferCNV's residual matrix, as we did for the synovial sarcoma example (Methods). Methods that identify normal cells themselves, such as CopyKAT, SCEVAN and Numbat, remove the need for a separate step \citep{gao2021copykat, defalco2023, gao2023numbat}.

The other limitations are shared, to different degrees, by all methods based on expression. Any expression difference between observations and references that spans many neighbouring genes can resemble a CNA. Batch and platform effects are one source: in a multi-platform benchmark, cells grouped by platform rather than by clone until the data were batch-corrected \citep{chen2025}. Losses are detected less sensitively than gains, which \citet{schmid2025} attribute to the difficulty of separating deletions from dropout in sparse data and to the lower gene density of regions that are commonly lost. Focal events that span few genes are smoothed away. The state labels are relative and nominal. Because each cell is centred on its median, a uniform change of ploidy cannot be seen, and in a highly aneuploid tumour the most common copy number appears neutral. The highest state groups all high-level gains (Section~\ref{sec:implementation}; Supplementary Fig.~\ref{fig:S6}). Per-cell calls are noisy, so the default analysis is by subcluster, and the partition then sets the resolution of the calls. Leiden subclustering can split subclones \citep{chang2026preprint}. On simulated subclones, the permutation-based \texttt{random\_trees} partition matched the truth more closely than the default Leiden partition, and per-cell HMM calls were much noisier than per-subcluster calls (Fig.~\ref{fig:subclusters}). Finally, inferCNV is slower than other methods \citep{schmid2025, chang2026preprint}. In our measurements, most of the run time on large data sets was spent in the Bayesian filter. Without the filter, run time grew nearly linearly with the number of cells, reaching about one hour for 20,000 cells with four threads (Fig.~\ref{fig:6}).

These results lead to a few practical recommendations.
\begin{itemize}
\tightlist
\item Choose the reference with care. Normal cells from the same samples, given as one group per cell type, are better than pooled references or references from other lineages or data sets.
\item Use subcluster-level calls rather than per-cell calls. With small data sets, \texttt{random\_trees} subclustering better approximates the number of subclones.
\item Interpret the state labels as relative levels.
\item For large data sets, skip the Bayesian filter, use the three-state HMM or subsample cell groups.
\end{itemize}

Several capabilities of newer methods are outside the expression model described here. Because the expression model ignores allelic imbalance, events that leave total copy number unchanged, such as copy-neutral loss of heterozygosity, are invisible to it, and it cannot tell which parental copy was lost. Allele-aware methods such as Numbat and XClone resolve these events \citep{gao2023numbat, huang2024xclone}, and an independent benchmark found Numbat the most accurate method when the allelic signal was adequate \citep{chang2026preprint}. inferCNV also does not segment the genome into breakpoints in genomic coordinates, estimate tumour ploidy, reconstruct a phylogeny of subclones, or model the spatial relationships between spots \citep{gao2023numbat, defalco2023, ma2024calicost}. The release described here also includes an allele-aware extension of inferCNV by Yu Zhong, which will be described separately. For many analyses, an expression-based method with a carefully chosen reference remains a simple and informative first step. Expression-based and allele-aware calls can also be compared to strengthen conclusions.
