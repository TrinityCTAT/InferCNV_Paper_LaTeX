\section*{Declarations}\label{sec:declarations}

\subsection*{Ethics approval and consent to participate}

This study reanalysed published data sets and collected no new samples. Patient consent and ethics approval for the tumour data sets were obtained by the original studies, as described in those publications.

\subsection*{Consent for publication}

Not applicable.

\subsection*{Use of generative AI}

Claude Opus 5.5 (Anthropic), used through Claude Code, assisted throughout the preparation of this manuscript. Starting from earlier text written by Brian Haas, Christophe Georgescu and Timothy Tickle, it helped to draft and edit the text; to write the analysis scripts and notebooks; to run the benchmarks and analyses and to produce the figures; and to implement and test changes to the inferCNV code described here. All analyses are scripted and the scripts are public, so every number and figure can be regenerated and checked (Availability of data and materials). Brian Haas reviewed the work and takes responsibility for the content.
