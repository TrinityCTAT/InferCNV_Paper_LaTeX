# InferCNV_Paper_LaTeX

LaTeX source of the inferCNV preprint, synced with Overleaf via GitHub sync. It is also a submodule (`latex/`) of [TrinityCTAT/InferCNV_Paper](https://github.com/TrinityCTAT/InferCNV_Paper), which holds the analyses behind the figures.

- `main.tex`: preamble, title, authors, section includes.
- `sections/*.tex`: one file per section, so collaborators can edit different sections without conflicts.
- `references.bib`: bibliography (natbib, `unsrtnat`); every DOI was verified against Crossref.
- `figures/`: figure files, generated by scripts in InferCNV_Paper/analyses.

Build: `latexmk -pdf main.tex` (pdfLaTeX, Overleaf's default). Red `[...]` notes (`\todo{}`) mark pending results and items to confirm.
